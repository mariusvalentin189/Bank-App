# 🏦 Bank App

A **desktop banking application** developed in **Python** using **PyQt6**, with an **SQL database** for managing user accounts and banking data.

> 🚧 **Project Status:** This project is currently **under development**. Some planned features have not yet been implemented.

---

## 🎯 Current Features

* 👤 User account creation and management.
* 🗄️ SQL database integration for persistent data storage.
* 🖥️ Desktop graphical user interface built with PyQt6.
* 🔐 Foundation for secure user and account management.

---

## 🛠️ Built With

* **Python**
* **PyQt6**
* **SQL**

---

## 🚧 Planned Features

* 💳 Deposits and withdrawals.
* 💸 Money transfers between accounts.
* 📊 Transaction history.
* 🔑 User authentication and login system.
* 🛡️ Additional data validation and security improvements.

---

## ▶️ Running the Project

Clone the repository, install the required Python dependencies, configure the SQL database, and run the application.
